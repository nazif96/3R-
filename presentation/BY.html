Probit bivarié récursif

\[ y_{i1} = \begin{cases} 1 & \text{si } y_{i1}^* > 0 \\ 0 & \text{si } y_{i1}^* \leq 0 \end{cases} \]

\[ y_{i2} = \begin{cases} 1 & \text{si } y_{i2}^* > 0 \\ 0 & \text{si } y_{i2}^* \leq 0 \end{cases} \]

Avec :

\[ y_{i1}^* = X_{i1}\beta_1 + u_{i1} \quad (1) \]

\[ y_{i2}^* = \theta y_{i1} + X_{i2}\beta_2 + u_{i2} \quad (2) \]

Modèle probit-probit ordonné

Un modèle avec une variable catégorielle : le temps de travail

\[ \text{Pour tout } k \in \{0, 1, 2\}, \]

\[ Y_1 = k \Leftrightarrow s_k < Y_1^* = X_1\beta + u_{i1} \leq s_{k+1} \]

  • Si \(k = 0\), \(Y_1^*\) représente l’absence de travail.
  • Si \(k = 1\), \(Y_1^* \leq 16\) heures.
  • Si \(k = 2\), \(Y_1^* \geq 16\) heures.

Modèle probit-probit ordonné

On note dans la suite les variables indicatrices.

  • \(Y_1^{1}\) le fait de travailler moins de 16 heures.
  • \(Y_{1}^{2}\) le fait de travailler plus de 16 heures.

Modèle probit-probit ordonné

Une variable catégorielle : la réussite universitaire

\[ y_{i2} = \begin{cases} 1 & \text{si } y_{i2}^* > 0 \\ 0 & \text{si } y_{i2}^* \leq 0 \end{cases} \]

avec:

\[ y_{i2}^* = Y_1^1\beta_{20}^1 + Y_1^2\beta_{20}^2 + X_2\beta_{21} + u_{i2} \]

La fonction de vraisemblance

La contribution individuelle à la vraisemblance \(P_1\) s’écrit, en notant \(\Phi_2(.,.,\sigma_{12})\) la fonction de répartition de la loi normale bivariée \(N(0, \Sigma)\), l’indice individuel \(i\) étant omis ci-après afin d’alléger les notations:

\[\begin{align*} P_1 &= \Phi_2(S_{y_1+1} - X_1\beta_1, -Y_{1}^1\beta_{20}^1 - Y_{1}^2\beta_{20}^2 - X_2\beta_{21}, \sigma_{12}) \\ &\quad - \Phi_2(S_{y_1} - X_1\beta_1, - Y_{1}^1\beta_{20}^1 - Y_{1}^2\beta_{20}^2 - X_2\beta_{21}, \sigma_{12}) \end{align*}\]

La fonction de vraisemblance

De même, par symétrie, la contribution individuelle à la vraisemblance d’une observation du sous-échantillon \(I_2\):

\[\begin{align*} P_2 &= \Phi_2(S_{y_1+1} - X_1\beta_1, Y_{1}^1\beta_{20}^1 + Y_{1}^2\beta_{20}^2 + X_2\beta_{21}, -\sigma_{12}) \\ &\quad - \Phi_2(S_{y_1} - X_1\beta_1, Y_{1}^1\beta_{20}^1 + Y_{1}^2\beta_{20}^2 + X_2\beta_{21}, -\sigma_{12}) \end{align*}\]
